# 밑줄이 머문 자리 — 기획서 발췌 (MVP 범위 / 화면 구성 / 기능 명세 / 데이터 구조)

> 원본 기획서("문장 수집 앱 기획서 & 단계별 개발 프롬프트")에서 네 섹션을 그대로 옮긴 문서입니다. 내용을 임의로 바꾸지 않았습니다.

## MVP 범위

MVP는 "사진으로 문장을 담고, 내 생각을 붙이고, 다시 보여주는" 한 바퀴를 다루는 데 집중합니다. 크롬 확장, 위젯, 카드 디자인, 친구 기능은 이 한 바퀴가 돌아간 다음에 얹습니다.

| 기능 | 단계 | 이유 |
|---|---|---|
| 사진 촬영 또는 갤러리 캡처 등록 | MVP | 수집의 시작점이자 가장 큰 차별점 |
| OCR로 글자 추출 + 형광펜으로 한 줄만 선택 | MVP | "밑줄 친 문장만 저장"이 핵심 가치 |
| 텍스트 직접 입력·붙여넣기, 메모 파일 첨부 | MVP | OCR 실패 시에도 쓸 수 있어야 함 |
| 출처 지정(책·드라마·영화·TV·유튜브·SNS·기타), 저자·링크 기록 | MVP | 수집의 기본 메타데이터 |
| 문장별 "내 생각" 칸 | MVP | 정리 습관의 핵심 |
| 떠오른 순간 한 줄 기록(빠른 메모) | MVP | 문장 없이도 생각을 쌓을 수 있게 |
| 책 등록(검색·표지), 읽은 쪽수·진행률, 독서 타이머 | MVP | 요청하신 독서 기능의 최소 버전 |
| 위시리스트(볼 것·읽을 것) | MVP | 책 등록 흐름에 함께 들어감 |
| 복습: 오늘의 문장 + 간격 반복 알림 | MVP | 쌓아두기로 끝나지 않게 하는 차별점 |
| 검색·태그·색상 필터, 로그인·클라우드 백업 | MVP | 데이터를 잃지 않게 |
| 홈 화면 위젯(iOS·Android) | 2차 | 네이티브 설정이 필요해 MVP 이후가 안전 |
| Chrome 확장 프로그램(드래그 채집) | 2차 | 별도 프로젝트로 먼저 앱 데이터 구조가 정해져야 함 |
| 콘텐츠별 카드 디자인(영화 티켓, 음악 CD) + 포토카드 저장 | 2차 | 디자인 작업량이 큰 후반부 항목 |
| 웹 버전 본격 지원 | 2차 | 모바일 MVP 검증 뒤 확장 |
| 친구 공유, AI 취향 분석, 내보내기 | 3차 | 사용자가 쌓인 뒤에 가치가 생김 |

**MVP가 끝났는지 확인하는 기준**
- 책 페이지를 찍어 한 문장을 저장하기까지 약 30초 안에 끝난다(목표값, 실사용으로 조정).
- 본인이 일주일 동안 쓰면서 직접 문장 20개 이상을 저장하고 복습 알림을 열어 본다.
- 앱을 꺼도 데이터가 유지되고, 재로그인 후에도 복원된다.

## 화면 구성

하단 탭 5개(홈, 문장함, 가운데 추가 버튼, 독서, 나)로 구성하고, 가운데 추가 버튼 하나로 모든 수집이 시작되게 합니다. 모으는 순간의 마찰을 줄이는 것이 이 앱의 중심이기 때문입니다.

| 화면 | 탭 | 구성 요소 | 핵심 동작 |
|---|---|---|---|
| 홈 | 1 | 오늘의 문장 카드, 빠른 생각 입력창, 읽는 중인 책 진행률, 최근 수집 | 복습 카드 넘기기(기억났어요 / 다시 볼래요) |
| 문장함 | 2 | 문장 목록(최신순), 출처·태그·색상 필터, 검색 | 카드 탭하면 상세로 이동 |
| 추가 시트 | 3(가운데) | 사진 찍기, 갤러리에서 선택, 텍스트 붙여넣기, 한 줄 생각 | 선택한 방식으로 편집 화면으로 이동 |
| 편집(형광펜) 화면 | 수집 흐름 | 사진 위 OCR 텍스트 영역, 형광펜 도구, 출처 선택, 내 생각 입력칸 | 한 줄을 긋고 저장 |
| 문장 상세 | 문장함 하위 | 원문, 사진, 출처 정보, 내 생각 목록(추가 가능), 날짜 | 수정·삭제·생각 추가 |
| 독서(내 책장) | 4 | 읽는 중 / 완독 / 위시리스트 탭, 책 표지 그리드 | 책 탭하면 책 상세 |
| 책 상세 | 독서 하위 | 표지, 진행률 바, 타이머 시작, 이 책에서 모은 문장 | 쪽수 기록, 타이머 시작·종료 |
| 책 검색·등록 | 독서 하위 | 제목 검색, 표지 미리보기, 총 쪽수 | 등록 또는 위시리스트에 담기 |
| 나 | 5 | 복습 알림 시간, 테마, 백업, 로그아웃 | 알림 시간 변경 |

**핵심 수집 흐름(사진 기준)**
1. 가운데 추가 버튼에서 "사진 찍기"를 고른다.
2. 찍은 사진에서 글자가 자동으로 추출된다(OCR).
3. 형광펜으로 마음에 드는 한 줄을 선택한다.
4. 출처(책이면 등록된 책 선택)를 고른다.
5. "내 생각" 칸에 한 줄 적고 저장한다(생각은 비워도 저장 가능).

## 기능 명세

기능마다 "무엇을 하는지"와 "완성 기준"을 적어 두었습니다. 완성 기준은 Claude Code에 그대로 넘겨 테스트 기준으로 쓸 수 있습니다.

### F1. 사진으로 문장 수집 (촬영·OCR·형광펜)
- 카메라 촬영 또는 갤러리·스크린샷 선택으로 이미지를 등록합니다.
- 기기에서 OCR로 텍스트와 단어별 위치를 얻습니다. 한국어 인식률이 부족하면 클라우드 OCR로 보완합니다(도구별 한국어 지원과 비용은 만들기 전에 한 번 확인해야 합니다).
- 사진 위에서 한 줄을 드래그하면 형광펜이 칠해지고, 선택한 텍스트가 문장 초안이 됩니다. 여러 줄이나 여러 형광펜도 허용합니다.
- 인식된 텍스트는 탭해서 직접 고칠 수 있습니다.

**완성 기준**: 선택한 텍스트가 저장되고, 원본 사진과 형광펜 좌표를 다시 열면 그대로 보인다.

### F2. 텍스트·메모 첨부 수집
- 클립보드 붙여넣기, 직접 타이핑, 텍스트 파일(메모장 내보내기) 첨부를 지원합니다.
- 첨부한 메모는 여러 줄이면 줄 단위로 형광펜을 칠해 한 문장씩 분리 저장할 수 있습니다.
- 안드로이드·iOS 공유 메뉴에서 밑줄이 머문 자리로 보내기를 고르면 바로 들어오는 것은 2차 후보입니다.

### F3. 출처 관리
- 출처 종류: 책, 드라마, 영화, TV 프로그램, 유튜브, SNS, 기타.
- 공통 필드는 제목·저자(또는 출연·채널)·링크이고, 책은 독서 등록 데이터와 연결됩니다.
- 자주 쓰는 출처는 최근 목록으로 한 번에 선택합니다.

### F4. 내 생각 기록
- 문장 상세에 "내 생각" 칸이 있고, 날짜별로 여러 개를 쌓을 수 있습니다(같은 문장을 다음에 다시 보고 생각이 달라지는 것을 남기기 위함).
- 홈의 "떠오른 순간" 입력창은 문장 없이 생각만 기록합니다. 나중에 특정 문장이나 책에 연결할 수 있습니다.
- 생각에 태그(예: 일, 관계, 성장)를 달아 주제별로 모아 볼 수 있습니다.

**완성 기준**: 문장 없는 생각도, 생각 없는 문장도 저장되고 각각 목록에 보인다.

### F5. 독서(책 등록·진행률·타이머)
- 책 제목이나 ISBN으로 검색해 표지·저자·총 쪽수를 가져와 등록합니다(도서 검색 API 후보는 데이터 구조 뒤의 개발 순서에 정리).
- 상태는 읽을 거야 / 읽는 중 / 완독입니다. 진행률 = 현재 쪽수 ÷ 총 쪽수.
- 타이머는 시작·일시정지·종료를 지원하고, 종료 시 읽은 쪽수를 입력하면 독서 기록(날짜, 분, 쪽)이 남습니다.
- 책 상세에서 그 책에서 모은 문장을 모아 볼 수 있습니다.

### F6. 복습 루프 (다시 만나게 하는 문장)
- 하루 한 번, 사용자가 정한 시간에 복습 대상 문장 1개를 알림으로 보냅니다.
- 간격은 1일, 3일, 7일, 14일, 30일입니다. "기억났어요"는 다음 간격으로, "다시 볼래요"는 1일로 되돌립니다.
- 새로 모은 문장은 일주일 이내에 복습 큐에 우선 올라갑니다. "지금 내 상황에 맞는 문장"(태그·생각 기반 추천)은 데이터가 쌓인 뒤 2차에서 더합니다.
- 복습 화면에서 바로 새 생각을 덧붙일 수 있습니다.

### F7. 위시리스트
- 볼 것(영화·드라마·TV)과 읽을 것(책) 두 목록을 두고, 다 본 뒤 "보는 중/완료"로 옮깁니다.
- 읽을 것을 "읽는 중"으로 바꾸면 독서 탭의 책 상세로 넘어갑니다.

### F8. 검색·필터·백업
- 문장 텍스트·생각·출처·태그 전체 검색을 지원하고, 출처 종류·날짜 범위 필터가 있습니다.
- 로그인하면 데이터가 자동으로 클라우드에 백업되고, 오프라인에서도 저장 후 나중에 동기화됩니다.

### 2차 기능 메모
- **Chrome 확장 프로그램**: 웹 페이지에서 텍스트를 드래그하면 출처 URL과 함께 밑줄이 머문 자리 계정으로 전송합니다. 앱과 같은 백엔드를 씁니다.
- **홈 화면 위젯**: 오늘의 복습 문장을 홈 화면에 표시합니다.
- **콘텐츠별 카드**: 영화는 티켓, 음악은 CD 모양의 카드와 포토카드 이미지 저장.

## 데이터 구조

테이블 7개로 시작합니다. 핵심 관계는 "출처 → 문장 → 생각"이고, 문장과 생각 모두 출처 없이도 존재할 수 있게(비워두기 허용) 설계합니다. 모든 테이블에 user_id를 두고, 본인 데이터만 읽고 쓰도록 행 단위 보안(RLS)을 겁니다.

| 테이블 | 주요 필드 | 관계와 메모 |
|---|---|---|
| profiles | id(로그인 계정 id), nickname, review_time(복습 알림 시간), created_at | 로그인 계정과 1:1 |
| sources | id, user_id, type(book·drama·movie·tv·youtube·sns·etc), title, creator, url, cover_url, external_id(ISBN 등), status(wish·ongoing·done), created_at | 책·영화 등 모든 출처와 위시리스트를 한 테이블에 담음(status로 위시리스트 구분) |
| book_details | source_id(기본키), total_pages, current_page, started_at, finished_at | sources와 1:1, type이 book일 때만 사용 |
| quotes | id, user_id, source_id(비워도 됨), text, image_path, highlight_boxes(형광펜 좌표 JSON), page_number, tags(목록), created_at, updated_at | sources와 N:1 |
| thoughts | id, user_id, quote_id(비워도 됨), source_id(비워도 됨), body, tags(목록), created_at | quotes와 N:1, 문장 없는 순간 생각도 저장 |
| reading_sessions | id, user_id, source_id, started_at, ended_at, minutes, pages_read | 독서 타이머 기록, sources와 N:1 |
| review_schedule | quote_id(기본키), user_id, interval_days, next_review_at, last_result, review_count | quotes와 1:1, 복습 대상과 다음 날짜 관리 |

이미지는 별도 저장소(Storage)에 사용자id/연월/파일명 경로로 올리고, quotes.image_path에 경로만 저장합니다. highlight_boxes는 OCR 결과의 단어 위치 중 선택된 범위를 `[{x, y, w, h}]` 형태로 저장해 나중에 같은 형광펜을 다시 그립니다.
